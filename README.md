# 🧙‍♂️ L'Académie des Magiciens des Nombres

Jeu éducatif interactif pour apprendre et maîtriser les tables de multiplication et d'addition (pour enfants de 9 ans, CE2 / CM1).

---

## 🚀 Déploiement sur Vercel (En 2 minutes)

### Méthode 1 : Via l'interface web Vercel (Sans ligne de commande)
1. Créez un compte gratuit sur [vercel.com](https://vercel.com).
2. Cliquez sur **"Add New Project"** -> **"Import Git Repository"** (ou glissez le dossier du projet).
3. Cliquez sur **"Deploy"**.
4. 🎉 Votre jeu est immédiatement en ligne sur une adresse HTTPS sécurisée (ex: `https://mon-jeu-magique.vercel.app`) !

---

### Méthode 2 : Avec la commande Vercel CLI
Dans votre terminal :
```bash
npm install -g vercel
vercel
```
Suivez les 3 questions à l'écran, et le site est en ligne instantanément !
